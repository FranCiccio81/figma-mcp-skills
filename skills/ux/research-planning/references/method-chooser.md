# Method chooser

| Need | Behavioural (what people do) | Attitudinal (what people say) |
|---|---|---|
| **Why, how (qualitative)** | Contextual inquiry, field visits, usability tests, diary studies | In-depth interviews, focus groups (use sparingly), card sorting |
| **How many, how much (quantitative)** | Analytics, A/B tests, tree testing, unmoderated benchmarks | Surveys, desirability studies, Kano surveys |

| Stage | Typical methods |
|---|---|
| Explore a problem space | Interviews, contextual inquiry, diary studies, analytics review |
| Define and prioritise | Survey to size problems, opportunity scoring, card sorting |
| Evaluate solutions | Usability testing, tree testing, first-click tests, A/B tests |
| Monitor after launch | Analytics, satisfaction surveys, support ticket analysis |

Rules of thumb:

- Pair a quantitative signal with a qualitative explanation.
- Self-reported future behaviour ("would you use...") is weak evidence.
- Five to eight interviews per segment usually reveal the main themes for a focused question;
  stop when new sessions stop adding themes.
